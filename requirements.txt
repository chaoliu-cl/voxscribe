# COMPATIBILITY NOTES

# KNOWN ISSUES:
# 
# 1. PySide6 and Python 3.13+:
#    - PySide6 6.7.x is the last version to support Python 3.12
#    - Python 3.13+ support coming in PySide6 6.8+
#    - Python 3.14 support timeline unclear
#
# 2. NumPy 2.0+:
#    - NumPy 2.0 introduced breaking changes
#    - Many scientific packages still require NumPy 1.x
#    - Constraint to <2.0.0 prevents upgrade issues
#
# 3. PyTorch installation:
#    - CPU vs GPU versions are different packages
#    - CUDA version must match your NVIDIA driver
#    - Use --extra-index-url for GPU versions
#
# 4. Faster-Whisper models:
#    - Downloaded automatically on first use
#    - Stored in ~/.cache/huggingface/
#    - Large models (5+ GB) - ensure sufficient disk space
#
# ============================================================================
# INSTALLATION INSTRUCTIONS
# ============================================================================

# RECOMMENDED INSTALLATION PROCESS:
#
# 1. Create virtual environment:
#    python -m venv voxscribe_env
#    source voxscribe_env/bin/activate  # Linux/Mac
#    # OR
#    voxscribe_env\Scripts\activate     # Windows
#
# 2. Upgrade pip:
#    pip install --upgrade pip
#
# 3. Install requirements:
#    pip install -r requirements.txt
#
# 4. For GPU support (NVIDIA):
#    # First, check your CUDA version:
#    nvidia-smi
#    
#    # Then install matching PyTorch (example for CUDA 11.8):
#    pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu118
#
# 5. Verify installation:
#    python -c "import PySide6; import faster_whisper; print('✓ All dependencies OK')"
#
# ============================================================================
# TROUBLESHOOTING
# ============================================================================

# Problem: "ModuleNotFoundError: No module named 'PySide6'"
# Solution: Ensure Python version is 3.9-3.12
#           pip install --upgrade PySide6
#
# Problem: "faster-whisper import error"
# Solution: pip install --upgrade faster-whisper ctranslate2
#
# Problem: GPU not detected
# Solution: 1. Check NVIDIA driver: nvidia-smi
#           2. Install correct CUDA PyTorch version
#           3. Verify: python -c "import torch; print(torch.cuda.is_available())"
#
# Problem: "Illegal instruction" error
# Solution: CPU doesn't support AVX2 - use older faster-whisper
#           pip install faster-whisper==0.10.0
#
